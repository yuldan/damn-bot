## Unreleased

### Added
- `journal`: action journal F2 (`internal/journal` + `internal/ctxdb/journalstore`) — before/after image disimpan sebagai blob content-addressed, baris `actions` + event `tool_dispatch` ditulis dalam satu transaksi sebelum side effect; `Get`/`List` melaporkan aksi kedaluwarsa (`T_cut` 30 hari / 2 GiB) dan turn yang masih terbuka (ADR-117, SPEC §18.1).

### Fixed

- `cmd/damnbot`: `run` mencetak error validasi flag (prompt hilang, `--output` tidak dikenal) ke stderr sebelum exit 2; error dari parser `flag` tetap dicetak sekali oleh paket `flag` (defect A4 matriks skenario LLM).
- `cmd/damnbot`: composition root headless menyambungkan `exec.Sessions` (dan menutupnya lebih dulu saat shutdown), sehingga `shell` dengan `session` benar-benar berjalan alih-alih `module_unavailable`; varian schema yang mengiklankan `session` kini cocok dengan ketersediaannya (C15). Penolakan auto-mode untuk `echo` tanpa `shell_allow` tetap benar (ADR-079).

- `codetools`: deskripsi `write_file` menyatakan bahwa `tag` harus dihilangkan untuk membuat file baru; `tag` pada path yang belum ada tetap `not_found` dengan hint "omit tag to create a new file" (C13).
- `codetools`: `grep` menerima `type:"text"` dan `type:"file"` sebagai alias semua file yang dipindai, tidak lagi menolaknya sebagai bahasa tak dikenal (C14).
- `provider`: error auth tidak lagi mengulang status numerik (`HTTP 401 401`) ketika provider menaruh status yang sama di `error.code` (B8).
- `ci`: bump Go to 1.26.10 (GO-2026-6809 — crypto/x509 intermediate cert distrust); pin `go` di `go.mod`, `bench/go.mod`, `tools/go.mod` dan baris Status ENGINEERING ikut naik.
- `ctxdb`: `CreateSession` menyimpan `Session.Model` dan `Session.ConfigSHA` yang sebenarnya, bukan placeholder `'test/model'`/`'cfg'`.
- `exec`: sweep marker tidak lagi berhenti pada pemindaian bersih pertama setelah leader exit — proses yang sedang di antara dua `execve` melaporkan environ kosong/parsial sehingga lolos dari `markerPids`; sweep mengonfirmasi dengan pemindaian bersih kedua (P24.1, ADR-105).
- `tools`: `shell` tidak lagi menurunkan mode eksekusi — `shell_allow` yang muncul/hilang/berubah argv antara `Inspect` dan `Run` menghasilkan `denied`, bukan `sh -c`; `cwd` di luar root ditolak `outside_workspace`; `Effect` memakai `cwd` panggilan; agregat inline yang habis tidak direset; stdin kosong = `nil`; `EnvPolicy.Secrets` (scope binary) diteruskan (REVIEW-F1-SEC7 TL7-4/5/6/7/8/10, ADR-109).
- `tools`: pipeline tidak lagi melaporkan sukses untuk `Result{Err:…}`/`OK:false`, menolak `NewDispatcher` tanpa `Redactor`, dan menetralkan penutup `<untrusted>` dalam segala kapitalisasi; `DispatchPrepared` menuntut otorisasi, menegakkan `denied`/`denied_path`, dan menolak eksekusi kedua (REVIEW-F1-SEC7 TL7-1/2/3/11, ADR-109).
- `loop`: hasil tool tidak lagi hilang saat batch berakhir terminal — setiap call yang sudah berjalan punya `tool_result`, call yang tidak pernah mulai ditandai `not_started`, grant `allow_session` cached tetap menyetel `Prepared.Approved`, `KillGrace` hanya membatasi turn yang dibatalkan, dan redaksi lintas-delta menutup secret yang terpecah antar-delta teks maupun argumen tool (REVIEW-F1-SEC8 LP8-16..20, ADR-110).
- `loop`: `Store.Append` mengembalikan id event dan `Ledger.Record` menerima id tersebut; `llm_call` di-append sebelum baris `usage_ledger` sehingga `ledgerstore` dapat menautkan `event_id` sesi yang sama (trigger 1811), bukan placeholder 0 (ADR-110).
- `provider`/`netx`: endpoint jahat tidak lagi bisa memicu CPU/memori tak sebanding — nama tool di-`append` dan dibatasi 256 B, ≤ 256 entri `tool_calls` per chunk dan setiap fragmen dihitung ke cap respons, reasoning dihitung termasuk salinan replay ter-quote; egress Inference tidak pernah mengikuti redirect (3xx = `bad_request`), purpose lain membuang header kredensial lintas host dan menolak https → http; fallback dilaporkan sebelum dan sesudah setiap percobaan termasuk yang gagal (REVIEW-F1-SEC3 PROV-M1..M5, ADR-100, ADR-102).
- `provider`: decoder delta tidak lagi merekursi tanpa batas saat melewati nilai JSON bersarang — `skip` iteratif dan nesting dibatasi 10.000 seperti encoding/json; frame SSE 4 MiB berisi `[` kini `errJSON`, bukan stack overflow fatal (REVIEW-F1-SEC3 PROV-B1, ADR-102).
- `budget`: biaya ledger tidak lagi bisa negatif atau mendekati 0 — token > 10¹², biaya provider > 10⁶ USD (termasuk +Inf), harga negatif, dan overflow tokens × harga ditolak `ErrInvalidUsage` (aritmetika tercek); test append-only `usage_ledger` kini non-vakum untuk UPDATE dan DELETE (REVIEW-F1-SEC3 LED-1..3, ADR-101).
- `netx` (DLP): batas kerja `2·len + 2 KiB` yang menolak request sah dengan token double-encoded diganti batas lapisan ≤ (1+3)·len; pola §14.3 dipindai atas run non-whitespace utuh yang memuat byte hasil decode (seluruh lapisan bila ada header `authorization`/PEM) dan secret di sekitar byte yang berubah (jendela dihitung setelah folding CR/LF), sehingga token dengan konteks > 256 B (JWT, userinfo URL) dan secret yang dipisah baris baru tetap diblok; secret pendek memakai anggaran verifikasi terpisah; daftar kandidat escape dibatasi (REVIEW-F1-SEC1 NETX-15/16, REVIEW-F1-SEC3 NETX-26..28, ADR-100).

- `netx/retry`: satu kebijakan retry P6 (kelas typed, backoff 1 s/4 s ±20 %, `Retry-After` ≤ 30 s, maks 3 attempt) + circuit breaker in-process (ADR-100).

- `netx`: satu-satunya pembuat klien HTTP — transport ber-pool bersama, dial non-loopback ditolak di binary test (E-69) dan mode offline, egress tool hanya ke IP publik (anti SSRF), egress `background` dapat dimatikan, watchdog stream TTFB/idle (GAP-REL-07), error fase koneksi vs putus di tengah request (EC-PROV-030) (ADR-100).
