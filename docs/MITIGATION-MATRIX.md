# MITIGATION-MATRIX — kelemahan hermes → mitigasi Damn-Bot

Setiap kelemahan hermes yang teraudit dipetakan ke mekanisme konkret Damn-Bot, cara verifikasi terukur, dan sisa risiko. Rujukan hermes relatif ke root `hermes-agent` (snapshot `868b9f244f`). Sumber: [`BASELINE-hermes.md`](BASELINE-hermes.md), audit file tools & eksekusi (dikutip di [`CODE-TOOLS.md`](CODE-TOOLS.md) §0 dan [`EXEC-AND-CODING.md`](EXEC-AND-CODING.md) §0), [`FEATURE-PARITY.md`](FEATURE-PARITY.md), [`EDGE-CASES-hermes.md`](EDGE-CASES-hermes.md). Rujukan tanpa nomor baris yang belum diverifikasi ulang ditandai `[baris tidak terverifikasi]`.

Kolom "Verifikasi" merujuk test/gate yang menjadi syarat merge (PR) atau rilis (RC); angka target juga tercatat di [`SCORECARD.md`](SCORECARD.md).
