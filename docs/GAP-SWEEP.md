# GAP-SWEEP — kelemahan hermes-agent yang belum tercakup Damn-Bot

Audit independen terhadap `hermes-agent` commit `868b9f244f` (read-only), dibandingkan dengan daftar cakupan Damn-Bot dari brief plus isi `SPEC.md`, `docs/BASELINE-hermes.md`, dan `docs/FEATURE-PARITY.md` yang sudah ada pada 2026-10-17. Item yang ternyata sudah diatur SPEC tidak dilaporkan sebagai gap. Item seperti itu dicatat di §5. Rujukan `file:line` relatif terhadap root hermes. Tanda **✔** berarti auditor sudah membaca ulang bukti itu langsung. Bukti lain berasal dari sweep per area yang membaca file sumbernya. Klaim yang tidak diamati langsung ditandai `[INFERENCE]`.

Metode: sweep sistematis per direktori top-level (8 lane paralel: `agent`+root runtime, `tools`, `gateway`+platform, `hermes_cli`+root CLI, plugin/katalog/skill/MCP, cron/pm/ACP/TUI/platform, web/apps/website/locales, state/infra/CI/test). Tiap lane membaca AGENTS.md/README lokal, mendaftar modul, lalu mencari sinyal: komentar bug/`#issue`/workaround, except yang ditelan, retry/sleep, default yang merugikan, duplikasi, UX membingungkan, risiko keamanan/privasi/ToS, dan biaya operasional. Ada 145 temuan mentah dari lane ditambah 1 temuan auditor (COST-16, hasil pengukuran). Dari jumlah itu, 12 dibatalkan karena sudah diatur SPEC (§5.2) dan duplikat antar-lane digabung (mis. backup, MCP trust/rug-pull, installer, cache web, biaya media, cancel). Hasil akhirnya 118 gap.

Catatan sinyal:

- **Jumlah TODO rendah tidak berarti utang teknisnya rendah.** Hermes melacak utang lewat rujukan issue. Contohnya: 184 file `tools/` berisi rujukan `#NNNN`, ≥ 90 rujukan di `cron/scheduler.py`, dan 44 file e2e `known_gate` (REL-14).

- Ada 56 workflow CI; hanya 1 yang memakai `--fail-on-skip`.
- `.env.example`: 143 assignment VAR dalam 563 baris. `cli-config.yaml.example`: 2.352 baris.
- Biaya idle gateway (diukur auditor, Python 3.14.7, `HERMES_HOME=/tmp/hm_gap`): `import gateway.run` saja butuh **2,4 s**, memuat **1.090 modul**, dengan VmHWM **92 MB**, sebelum ada adapter yang berjalan. Baseline interpreter kosong 12,7 MB.
